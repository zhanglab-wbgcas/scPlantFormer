scPlantFormer Documentation
==========================

scPlantFormer provides tools for cross-dataset cell-type annotation, multi-modal
pre-training, and single-cell dataset integration across species, tissues, and
experimental conditions.

Main Features
-------------

- Cross-dataset cell-type annotation workflows.
- Multi-modal pre-training for scRNA-seq and scATAC-seq.
- Integration notebooks across batches, species, tissues, and modalities.

Repository Layout
-----------------

- ``Tutorial/``: notebooks and scripts for integration and annotation.
- ``model/``: model training and inference utilities.
- ``Baseline_scLLM/``: baseline model resources.

Getting Started
---------------

1. Install dependencies listed in the project ``requirements.txt``.
2. Explore notebook examples under ``Tutorial/``.
3. Run model utilities from ``model/`` for training or inference tasks.
