# scPlantFormer Documentation

scPlantFormer provides tools for cross-dataset cell-type annotation, model pre-training on multi-modal single-cell data, and integration across species, tissues, and experimental conditions.

## Key capabilities

- Cross-dataset and inner cell-type annotation.
- Pre-training on multi-modal single-cell datasets (scRNA-seq / scATAC-seq).
- Integration workflows across batches, species, and tissues.

## Repository structure

- `model/`: model definition and inference/evaluation utilities.
- `Tutorial/`: notebooks and scripts for integration and annotation examples.
